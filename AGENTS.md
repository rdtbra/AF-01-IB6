# Instruções do repositório

## Estudo e organização de arquivos

- Leia agora o `.work/doc/CONTEXT.md`.
- Preserve os fontes originais do repositório. Não substitua nem reformate arquivos originais para criar visões de estudo, salvo pedido explícito.
- Mantenha em `.work/remote/` as cópias de estudo que precisam conservar a mesma estrutura relativa e, quando necessário, a mesma numeração de linhas dos fontes originais.
- `.work/remote/` é material de trabalho ignorado pelo Git e não deve ser usado como entrada de build por engano.
- `.work/doc/CONTEXT.md` é a documentação canônica do estudo e deve permanecer versionada; não a inclua nas regras de ignorados.
- Ao concluir uma decisão estrutural ou uma descoberta importante, atualize `.work/doc/CONTEXT.md`.
- Ao mostrar código solicitado para navegação no estudo, preserve os números de linha e use indentação de dois espaços quando isso tiver sido pedido.
